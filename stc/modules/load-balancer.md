### Load Balancer

Create a Pulumi `ComponentResource` module under `modules/load-balancer` to create a GCP global external application load balancer.

* **Additional dependencies:** `@pulumi/gcp`, `@pulumi/pulumi` (included in calling stack's `package.json`)

> **Design note:** This module currently supports global external application load balancers with bucket backends only. Regional LBs, service backends, and split-backend modules are out of scope.

> **Assumption:** The calling project must have `compute.googleapis.com` enabled (which auto-creates the LB service agent). This module does not enable APIs.

* Accept an input based on the following YAML definition

```yaml
name: <string, required — GCP resource name prefix. Validated: ^[a-z]([-a-z0-9]*[a-z0-9])?$, max 63 chars>
project: <project ID string>
type:
  application:
    external:
      regionGlobal:
        frontend:
          <frontend_name>:
            description: <string (optional, default: "Frontend <key> for <name>")>
            protocol:
              type: <[HTTP | HTTPS]>
              certificateMap: <short name of a certificate map (required when protocol.type = HTTPS); the module expands it to the full certificate-manager resource path>
            ipVersion: <[IPv4 | IPv6] (optional, default: IPv4)>
            ipAddress: # (optional - default to ephemeral)
              type: <[ephemeral | static] >
              addressName: <name of a reserved static IP address (required when ipAddress.type = static)>
            port: <number (optional), default: 80 when HTTP, 443 when HTTPS>
        backend:
          <backend_name>:
            bucket:
              description: <string (optional, default: "Backend <key> for <name>")>
              bucketName: <bucketName>
            cloudCDN: # (optional)
              enabled: <[ true | false ]>
              cacheStaticContentSettings: # (optional — all values default to 3600 seconds)
                clientTTL: <number, seconds (optional, default: 3600)>
                defaultTTL: <number, seconds (optional, default: 3600)>
                maximumTTL: <number, seconds (optional, default: 3600)>
        routing:
          mode: advancedHostAndPathRule
          defaultBackend: <backend_name — must match a key in `backend`>
          rules: # (optional)
            <host>: # single hostname string (wildcards allowed, e.g. "*.example.com")
              rule: # conforms to Pulumi gcp.compute.URLMapPathMatcherArgs (minus `name`, generated by module)
                # `defaultService`, `pathRules[].service`, and `routeRules[].service` reference backend keys (not raw GCP paths).
                # The module resolves these keys to backend bucket self-links.
                # EXAMPLE:
                # defaultService: my_backend
                # routeRules:
                # - matchRules:
                #   - fullPathMatch: /
                #   priority: 1
                #   service: my_backend
                #   routeAction:
                #     urlRewrite:
                #       pathPrefixRewrite: /index.html
labels: # (optional) — merged per [CONV-LABELS]
```

* Requirements
  * Input Types
    * `project`, `certificateMap`, `bucketName`, `addressName`: [CONV-INPUT]. Construction-time name validation is skipped for unresolved Outputs (only resolved plain strings are validated).
  * Validation
    * `name`: Must match `^[a-z]([-a-z0-9]*[a-z0-9])?$`, max 63 characters. Validated at construction time.
    * `project` must be provided. Must be a GCP project ID string (e.g. `my-project-a1b2`), not a numeric project number.
    * `protocol.certificateMap` must be provided when `protocol.type` = `HTTPS`. Validated at construction time (error if HTTPS without a certificate map).
    * Enum fields are validated at construction time: `protocol.type` ∈ {`HTTP`, `HTTPS`}, `ipVersion` ∈ {`IPv4`, `IPv6`}, `ipAddress.type` ∈ {`ephemeral`, `static`}, `routing.mode` = `advancedHostAndPathRule`.
    * External resource references (`certificateMap`, `bucketName`, `addressName`): [CONV-VALIDATE-API] — existence deferred to GCP API at apply time.
  * Labels
    * Optional `labels` input. Merge per [CONV-LABELS]: user-provided labels → module defaults (`module: "load-balancer"`, `deployed_by: "pulumi"`). Applied to all resources that support labels.
  * `type` must be provided
    * `application` must be provided. Only `application` supported at this time
      * `external` must be provided. Only `external` supported at this time
        * `regionGlobal` must be provided. Only `regionGlobal` supported at this time
          * Create an external global application load balancer (latest generation)
            * Load balancer name = `name`
            * `frontend` must consist of one or more entries. For each entry, create a frontend configuration:
              * Name = `<name>-<key>`
                * Target HTTP/HTTPS proxy name = `<name>-<key>-proxy`; references the single URL map from `routing` (`<name>-urlmap`)
                * Global forwarding rule name = `<name>-<key>-fr`
              * Description = `description` or `"Frontend <key> for <name>"` if not provided
              * Protocol = `protocol.type`
              * Certificate Map (where protocol = HTTPS) = `certificateMap` short name, expanded by the module to `//certificatemanager.googleapis.com/projects/<project>/locations/global/certificateMaps/<certificateMap>`
              * SSL Policy (where protocol = HTTPS) = GCP Default
              * HTTP/3 QUIC negotiation (where protocol = HTTPS) = Automatic (default)
              * Early data (0-RTT) (where protocol = HTTPS) = Disabled
              * Network Service Tier = Premium (always; required for global ALBs)
              * IP Version = `ipVersion`. Default to IPv4 if not provided
              * IP Address = `ipAddress`. Default to ephemeral if not provided. Static IP addresses must be provisioned externally; this module references them by name.
                * Where provided, `type` must be `ephemeral` or `static`
                * Where `type` = `static`, `addressName` must be provided and must reference a **global external** address whose IP family matches `ipVersion`. Existence validated at apply time per [CONV-VALIDATE-API].
              * Port = `port`. Default to 80 (HTTP) or 443 (HTTPS)
            * `backend` must consist of one or more entries. For each entry, create a backend configuration:
              * `bucket` must be provided. Only `bucket` supported at this time
                * Backend Bucket Name = `<name>-<key>-bucket`
                * Description = `description` or `"Backend <key> for <name>"` if not provided
                * Cloud Storage Bucket = `bucketName`
                * On creation of the backend bucket, resolve the project number from `project` (via `gcp.organizations.getProject`), then grant `roles/storage.objectViewer` on the Cloud Storage bucket (`bucketName`) to the LB service account `service-<project-number>@https-lb.iam.gserviceaccount.com` (auto-created when `compute.googleapis.com` is enabled). Validated — this grants the global ALB read access to a private origin bucket.
              * If `cloudCDN.enabled` = true
                * Enable Cloud CDN
                * Cache mode = Cache static content
                * Client TTL = `cacheStaticContentSettings.clientTTL` (default: 3600 seconds)
                * Default TTL = `cacheStaticContentSettings.defaultTTL` (default: 3600 seconds)
                * Maximum TTL = `cacheStaticContentSettings.maximumTTL` (default: 3600 seconds)
            * `routing` must be provided
              * `mode` = `advancedHostAndPathRule` (only supported mode at this time)
              * `defaultBackend` must reference a valid key from `backend`. Validated at construction time.
              * Create a URL Map (named `<name>-urlmap`) with a single default route directing all traffic to the referenced backend
              * If `rules` provided:
                * At least one `host` entry must exist. Each key is a single hostname string (wildcards allowed, e.g. `*.example.com`)
                  * `<host>` is an FQDN and is not a valid GCP resource name, so derive a stable `<hostSlug>` for resource naming: lowercase, replace `*` with `wildcard`, replace every character not in `[a-z0-9]` with `-`, collapse repeated `-`, and strip leading/trailing `-` (e.g. `*.example.com` → `wildcard-example-com`). The slug is deterministic so names stay stable across runs.
                  * For each `host` entry:
                    * Create a URL map host rule mapping `host` to a path matcher named `<name>-<hostSlug>`
                      * Hosts = `host`
                      * Path matcher = `rule`, which must conform to Pulumi `gcp.compute.URLMapPathMatcherArgs` (minus `name`, which the module generates as `<name>-<hostSlug>`)
                        * `rule` must exist
                        * Backend-key resolution: the module treats the following `rule` fields as backend keys (defined in `backend`) and resolves each to the created backend bucket self-link at apply time: `defaultService`, `pathRules[].service`, and `routeRules[].service`. Values that are already raw GCP resource paths are rejected — only backend keys are accepted.
* Return
  * ipAddresses — `{ [frontendKey: string]: pulumi.Output<string> }` — IP address of each frontend's forwarding rule (ephemeral or static), keyed by frontend key
  * urlMapSelfLink — `pulumi.Output<string>` — Self-link of the URL Map
  * forwardingRuleSelfLinks — `{ [frontendKey: string]: pulumi.Output<string> }` — Self-link of each frontend's forwarding rule, keyed by frontend key
